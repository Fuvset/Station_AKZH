ЗАПУСК В VISUAL STUDIO
1. Нужна Visual Studio 2022 (17.8 или новее) с рабочей нагрузкой ".NET desktop development"
   (Разработка классических приложений .NET). Если VS старее - в Station.csproj замените
   net8.0-windows на net6.0-windows, а System.IO.Ports на версию 6.0.0.
2. Дважды щёлкните Station.sln.
3. Нажмите F5 (Запуск). Первая сборка сама скачает пакет System.IO.Ports (нужен интернет).

ФАЙЛЫ
Station/Program.cs      - точка входа
Station/MainForm.cs     - главное окно (панели, кнопки, Arduino)
Station/SchemePanel.cs  - отрисовка схемы (GDI+, событие Paint) и клики мышью
Station/Station.cs      - модель: пути, светофоры, стрелки, маршруты, логика

УПРАВЛЕНИЕ
- ПОЕЗДНЫЕ / МАНЕВРОВЫЕ - переключают список маршрутов.
- Клик по маршруту - установить, повторный клик - отменить.
- ЛКМ по номеру стрелки на схеме (или кнопки "Стрелки") - перевести вручную.
- ПКМ по участку пути - занять/освободить (красный).
- Проверка - зажигает все лампы на 1.5 сек. Убрать всё - сброс маршрутов и занятости.
- Arduino: выберите COM-порт в списке (9600 бод). Команды:
    SW5+ / SW5-    стрелка 5 плюс/минус
    SG3:1 / SG3:0  светофор с индексом 3 открыт/закрыт
    TEST           проверка ламп

ГДЕ ПРАВИТЬ СТАНЦИЮ
Station/Station.cs -> конструктор класса Station: Seg(...) участки, Sig(...) светофоры,
Sw(...) стрелки, R(...) маршруты. Буквы Н, Ч, М в названиях - кириллические.
